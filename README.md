# Traduction française de la documentation Python

Ce dépôt permet de contribuer aux traductions de
https://docs.python.org/fr/.

## Forges

Ce repo existe sur deux forges :

- https://git.afpy.org/AFPy/python-docs-fr/
- https://github.com/python/python-docs-fr/

Nous acceptons les contributions sur les deux forges.


## Progression

La progression peut être vue sur https://translations.python.org/
